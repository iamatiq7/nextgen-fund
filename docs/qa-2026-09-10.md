## Accessibility (axe-core audit, 2026-09-10)
- **Result: 0 violations across 9 views** (index, login, register, setup,
  portal, admin × 5 tabs) after fixes; keyboard checks all pass (logical tab
  order incl. login fields, Enter submits login end-to-end).
- **Critical bug found & fixed:** `portal.js` and `admin.js` rendered the
  header directly and never ran the i18n text pass — every static label,
  section title, table header and button text was **empty after login** (the
  original complaint). Both now call `C.renderFooter()` + `L.apply(document)`.
- **Header theme restored:** pages declared `<div id="site-header">` without
  the `site-header` class, so the designed black header never applied and
  header text sat light-on-light. All pages now use
  `<header class="site-header">` (also fixes the landmark/region finding).
- **Contrast:** `--faint` and `.footnote/.hint` greys darkened to meet
  WCAG AA (≥4.5:1) on the paper background; yellow stat card text fixed
  (a specificity clash made values white-on-yellow).
- Duplicate "Monthly" label removed from the portal; finance table's actions
  column header labeled via new `adm.fiActions` key (EN + বাংলা, 439/439 key
  parity maintained).

## Rollback
1. **GitHub Pages:** `git revert <commit>` (or `git reset --hard <previous>` +
   `git push --force-with-lease`) → Pages rebuilds the previous version.
   The previous release this replaces is commit `dcda511` (placeholders fix).
2. **Local verification of a rollback:** open the site in a private window,
   log in as a member, confirm the payment history renders (with the new
   auto-reseed, even an old browser DB self-heals or can be cleared via
   browser site-data settings).
3. **Preview host:** redeploy an earlier project snapshot by re-running the
   delivery with the previous files; the preview URL always serves the latest
   upload.
